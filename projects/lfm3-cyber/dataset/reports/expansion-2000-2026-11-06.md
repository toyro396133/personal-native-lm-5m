## גיוון תרחישים

ההרחבה כוללת 178 קבוצות תרחיש חדשות בנושאים כגון: התאמת CMDB ומלאי נכסים, הרשאות ספקים, חריגות מדיניות, DNS ו־IPv6, VPN, egress, TLS, חוקי Firewall, בריאות EDR, איכות detection, נרמול לוגים, lifecycle של IOC, אמינות מקורות, שימור ראיות, תגובה לאירועי זהות וכופרה, federation, cloud logging, supply chain, Kubernetes IAM, גבולות הרשאה במעבדות מורשות, API object authorization, OAuth, SSRF, העלאת קבצים, session security ושרשרת dependencies.

כל קבוצה כוללת חמש וריאציות: ניתוח ישיר, ניתוח ארטיפקט סינתטי, שאלת הבהרה, ניתוח ציר זמן ודוח מובנה. הווריאציות חולקות `scenario_id` ונשארות באותו split. החלוקה שזורה בין התחומים כדי למנוע מצב שבו תחום שלם מופיע רק ב־Validation או Test.

## גבולות איכות ומקור

- IDs: `lfm3c-pilot-1111` עד `lfm3c-pilot-2000`.
- Scenario IDs: `scenario-383` עד `scenario-560`.
- כל הרשומות החדשות מסומנות `pending` ב־verification וב־quality.
- לא בוצעה ביקורת מומחה ולא סומנה אף רשומה כ־verified.
- תוכן חדש נכתב כסינתזה מקורית; מקורות משמשים הקשר מושגי בלבד. לא הועתקו טקסטים, נתוני datasets, כללי Sigma, PCAPs או קוד.
- בדיקות המעבדה מוגבלות במפורש למכונות ולרשתות שהוקצו בכתב; אין יעד חיצוני.
- Test נשאר holdout. אין להשתמש בו לאימון או לכוונון.
- לא הורדו משקולות ולא בוצע אימון או tuning.

## המשך נדרש

להריץ CI מלא ולוודא סכימה, מזהים, כפילויות, בידוד splits וכיסוי מיומנויות. לאחר מכן אפשר להרחיב לסוגי קלט מובנים ועשירים יותר (שאילתות, תצורות מלאות, JSON audit events, תרחישי multi-turn אמיתיים ותרגילי triage מדורגים). ביקורת עצמאית מקצועית תבוצע רק בהוראה מפורשת נפרדת.
