# COMPASS V9.12 — ליבת זיכרון עובדת (אב־טיפוס)

> **זה COMPASS, לא אימון SELF.** זו תוכנית Python עצמאית ששומרת זיכרון אישי ועקרונות לכל פרויקט. היא אינה מבינה שיחה חופשית כמו מודל שפה, אינה מחוברת לחשבון ChatGPT שלך ואינה נפרסת לייצור.

## מה כבר עובד

- קובץ SQLite מקומי שנשמר בין הפעלות.
- זיכרון אישי משותף וזיכרון נפרד לכל פרויקט (`project_id`).
- עקרונות עם גרסה, תוכן, מקור, נימוק, תנאי תחולה ופרטי אישור.
- הצעת תיקון שלא משנה את הזיכרון עד שמישהו מאשר אותה במפורש.
- גרסאות ישנות נשמרות ביומן; שינוי חדש לא מוחק מדוע התקבלה החלטה קודמת.
- הודעות רגילות נשמרות כמידע שלא סווג ולא הופכות לעקרונות אוטומטית.
- בדיקה של שרשרת hash ביומן והתנגשות גרסאות בעת אישור.
- שליפת עקרונות מתאימים לפי הפרויקט הפעיל והקשר המשימה.

**גבולות חשובים:** `--actor` ו־`--author` הם מחרוזות שסופקו לתוכנית, לא משתמשים מאומתים. שרשרת hash אינה חתומה או מעוגנת חיצונית ויכולה לזהות שינויים גסים, לא תוקף בעל שליטה בקובץ כולו. תנאי תחולה הם התאמה מדויקת של זוגות מפתח־ערך, לא שיקול דעת סמנטי. כרגע מי שמשתמש בתוכנית הוא שמנסח את הרשומות ונותן את האישור.

## ניסיון מיידי — Windows PowerShell

דרוש Python 3.11 ומעלה; **אין צורך להתקין חבילות pip**, GPU או Docker.

אם עדיין אין לך את המאגר, הפעל ב־PowerShell:

```powershell
git clone https://github.com/toyro396133/personal-native-lm-5m.git
cd personal-native-lm-5m
git switch experiment/compass-v9-12
```

אם המאגר כבר קיים במחשב, בצע בתיקייתו `git fetch origin` ואז `git switch experiment/compass-v9-12` (ולפי הצורך `git pull`). חשוב: קובצי V9.12 נמצאים כרגע **בענף הניסוי**, ולא בענף הראשי.

בתיקיית המאגר:

```powershell
python .\experiments\compass_v9_12\demo_compass.py
```

ההדגמה משתמשת בנתונים פיקטיביים, מציגה שינוי של חזון פרויקט, שומרת את הסיבה לתיקון, מאשרת את התיקון, מבודדת פרויקט אחר, וסוגרת ופותחת את המסד מחדש. כברירת מחדל הדוגמה יוצרת קובץ זמני ומסירה אותו בסיום.

ליצירת מסד אישי חדש ריק (הקובץ נשאר במחשב שלך):

```powershell
python .\experiments\compass_v9_12\compass_core.py --db .\compass-local.sqlite3 init
```

להציע עיקרון לפרויקט, בלי להפעיל אותו עדיין:

```powershell
python .\experiments\compass_v9_12\compass_core.py --db .\compass-local.sqlite3 propose --scope project --project compass-lab --key vision --operation set --content "נלמד את מטרת הפרויקט ולא רק את הקוד הקיים" --reason "העיקרון הובהר בשיחה ובאישור מפורש" --expected-revision 0 --author local-user
```

הפקודה מחזירה מזהה `proposal_id`. יש להעתיק אותו **ידנית** לפקודת האישור (אין אישור אוטומטי):

```powershell
python .\experiments\compass_v9_12\compass_core.py --db .\compass-local.sqlite3 approve "PASTE_PROPOSAL_ID" --actor local-user --reason "בדקתי ואישרתי את הנוסח"
```

כדי להציג את הזיכרון המאושר של הפרויקט יחד עם העקרונות האישיים הרלוונטיים:

```powershell
python .\experiments\compass_v9_12\compass_core.py --db .\compass-local.sqlite3 resolve --project compass-lab
```

בדיקת תקינות היומן:

```powershell
python .\experiments\compass_v9_12\compass_core.py --db .\compass-local.sqlite3 verify
```

כדי לראות את כל האירועים ואת גרסאות העקרונות, השתמש בפקודות `timeline` ו־`list --history`.

## ממשק דפדפן מקומי בעברית

אפשר לעבוד בלי לזכור את פקודות `propose` ו־`approve`. מתוך תיקיית המאגר, לאחר מעבר לענף V9.12:

```powershell
python .\experiments\compass_v9_12\compass_ui.py --db .\compass-local.sqlite3 --port 8787 --open
```

ייפתח ממשק RTL מקומי בכתובת `http://127.0.0.1:8787`. אם הדפדפן אינו נפתח אוטומטית, העתק את הכתובת ידנית. הממשק מציג את העקרונות האישיים והפרויקטליים, את מקורם ונימוקיהם, רשימת הצעות שממתינות לאישור, טופס תיקון, בדיקת תחולה ויומן אירועים.

**בטיחות ושימוש:** השרת מאזין רק ל־`127.0.0.1`. פעולות שינוי דורשות אסימון ייעודי לסשן, ונבדקות נגד בקשות מאתר זר; אך **אין עדיין התחברות משתמש אמיתית** או מנגנון הרשאות ארגוני. השתמש רק במחשב מקומי שאתה סומך עליו, אל תחשוף את הפורט לאינטרנט ואל תשמור סודות בקובץ ניסוי. עצור את השרת באמצעות `Ctrl+C`.

הבדיקות של ממשק HTTP בודקות אישור/דחייה, חסימת שינויים ללא אסימון, מניעת בקשות ממקור זר, שמירת גרסאות, פתיחה מחדש וגבולות בין פרויקטים. אלו בדיקות פרוטוקול מקומיות; לא בוצעה עדיין בדיקת דפדפן גרפית מלאה.

## בדיקות ופסק הדין

[פרוטוקול ההערכה המקדים](PROTOCOL.md) · [בדיקות הקוד](test_compass_core.py) · [קובץ ההדגמה](demo_compass.py).

בדיקות הקבלה כוללות שמירה/פתיחה מחדש, בידוד פרויקטים, כמה עקרונות, אישור מפורש, גרסאות, אי־דריסה בעקבות הודעות רקע, תוקף תנאים, הצעות ישנות שנפסלות, שחזור ובדיקת שלמות.

**שער ההנדסה:** התוכנית והממשק המקומי חייבים לעבור את כל הבדיקות על Python 3.11, 3.12 ו־3.13 ולהציג הדגמה מלאה.

**שער הלמידה:** עדיין `NOT_YET_LEARNED`. לפני שנוכל לטעון ש־COMPASS באמת לומד את חזון המשתמש והפרויקט מעבודה שוטפת, נצטרך רכיב חילוץ/תיקון שנבדק על תמלילים אמיתיים, בעברית ובאנגלית, בלי תוויות שניתנו מראש ובלי אישור אוטומטי לא בטוח.

זו ליבה שימושית לבניית COMPASS ולא הוכחה שהמחקר הסתיים.
