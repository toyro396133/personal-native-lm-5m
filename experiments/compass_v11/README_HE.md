# COMPASS V11 — ניסוי הלמידה העצמאי הראשון

**לא SELF ולא GPT-6.** מדובר במסלול COMPASS עצמאי: שמירת היסטוריית משתמש/פרויקט, למידה מתוך משוב מפורש ורק אחר כך בדיקה על מקרה חדש.

## מה כבר נבנה

הקוד `online_compass.py` הוא רכיב CPU בפייתון רגיל, ללא התקנות חיצוניות. הוא מציג ניסיון *לפני* קבלת תשובה, ולאחר מכן מעדכן משקלים נלמדים בעזרת תשובה חד־משמעית בלבד. שומר משקלים נפרדים לפרויקטים ואירועים אישיים, מקורות והימנעות כשחסר מידע. הוא אינו מאשר עקרונות או מעביר אוטומטית מידע אישי בין פרויקטים.

**גבול המחקר:** זה עדיין לומד בחירות בין חלופות מתועדות, **לא** מנוע שמבין עצמאית חזון מטקסט חופשי. המודל מבוסס מאפייני מילים פשוטים, ומיועד לחשוף את מגבלות הלמידה לפני שאנחנו משקיעים במנגנון סמנטי.

## דוגמת קלט לא אמיתית (רק להמחשת פורמט)

שמור בקובץ `episodes.jsonl` שורה אחת לכל אירוע, בסדר המקורי. החלופות צריכות להיות כתובות **במקור עצמו** ולכלול תשובה מקורית של המשתמש, לא תשובה שמודל הסיק.

```json
{"id":"test.001","scope":"project","project_id":"fictional-project","source":"git:ffffffffffffffffffffffffffffffffffffffff:docs/fictional.md#L1-L8","question":"Which action should be chosen?","reply":"B","options":[{"id":"A","text":"Discard prior project findings"},{"id":"B","text":"Keep prior findings and improve them"}]}
```

הדוגמה לא נחשבת ראיה מחקרית. ה־Git SHA כאן בדוי.

## הרצה מקומית ב־Windows PowerShell

```powershell
git fetch origin
git switch experiment/compass-v11-standalone-longitudinal
python .\experiments\compass_v11\online_compass.py `
  --episodes .\episodes.jsonl `
  --report .\compass-v11-report.json `
  --state .\compass-v11-state-private.json
```

הדוח יבדיל בין כמות האירועים, כמות התשובות החד־משמעיות, ניסיונות חיזוי, הצלחות ושגיאות, וישווה ללומד שאינו לומד, לבחירה האחרונה ולאחזור פשוט. מומלץ לשמור את קובצי הקלט, המשקלים והדוחות מחוץ למאגר GitHub הציבורי, משום שהם יכולים להכיל מידע פרטי.

**מה עוד לא קרה:** לא הופעל ניסוי אמיתי על תשובות המשתמש עם חלופות מאומתות; בבדיקה ראשונית של 52 תחנות תחקיר נמצאו רק 8 תשובות העשויות להיות בחירות חד־משמעיות. חייבים ללמוד גם מתשובות חופשיות, תיקונים, הסתייגויות ותוצאות עבודה — בלי להמציא תוויות בידי מודל חיצוני.
