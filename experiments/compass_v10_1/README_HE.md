# COMPASS V10.1 — לומד מהתפתחות הפרויקט, בלי API

ב־V10 היה לנו מודל חזון **קבוע**. ב־V10.1 הוספנו מנגנון מתמשך: החלטות חדשות מוצעות לעדכון בנושאים מוגדרים, נבדקות לפני אישור, ויוצרות גרסאות בלי למחוק את ההיסטוריה. כך תדריך הפרויקט שניתן ל־GPT-6 יכול להשתנות לאורך זמן.

**גבול חשוב:** עדיין לא הוכחנו למידת הבנה עצמאית. השימוש במונח "למידה" כאן פירושו עדכון ושחזור של מצב ידע מאושר, ולא אימון משקלים או הסקת כוונות אוטונומית.

## הדגמה מתוך תיעוד חכם לב

המאגר הציבורי מכיל **רק קוד ובדיקות בדויות**. דוגמאות התיעוד האמיתיות נמסרו למשתמש בנפרד בקובץ פרטי בשם `COMPASS_V101_CHACHAM_PENDING_STAGES.json`. הקובץ כולל 13 הצעות GPT-6 בשלושה שלבים, עם גרסאות SHA ושורות מקור: ארבעה עקרונות מוקדמים, שלוש הכרעות ביניים, שישה עדכונים מאוחרים. שלושה מן העדכונים משנים נושא שכבר קיבל גרסה קודמת.

### שחזור ללא אישור אמיתי

ב־Windows, בתיקיית מאגר המחקר:

```powershell
git fetch origin experiment/compass-v10-1-learning-loop
git switch experiment/compass-v10-1-learning-loop
python .\experiments\compass_v10_1\chronological_study.py `
  --private-input "$env:USERPROFILE\Downloads\COMPASS_V101_CHACHAM_PENDING_STAGES.json" `
  --private-report "$env:USERPROFILE\Downloads\COMPASS_V101_REAL_RETROSPECTIVE_SIMULATION_RESULT.json"
```

מקום קובץ הקלט יכול להיות שונה. הסקריפט יוצר מסד זמני, מיישם אישורים מדומים שמסומנים באופן חד־משמעי כ**סימולציה בלבד**, בודק את הגרסאות ומשמיד את המסד. אינו משנה את חכם לב או את זיכרון המשתמש.

### שימוש אמיתי עם אישור אנושי

העתק פריט בודד מהקובץ הפרטי לקובץ JSON מקומי, והשתמש בערך `record` בלבד. דוגמה לפקודות:

```powershell
python .\experiments\compass_v10_1\learning_loop.py --db .\compass-private.sqlite3 propose --candidate .\candidate.json
python .\experiments\compass_v9_12\compass_ui.py --db .\compass-private.sqlite3 --port 8787 --open
python .\experiments\compass_v10_1\learning_loop.py --db .\compass-private.sqlite3 brief --task "תכנן שיפור במסלולים לשנה הבאה"
```

הצעה חדשה **אינה פעילה לפני אישור** בממשק הסקירה. אם נושא השתנה, `expected_revision` חייב להתאים לגרסה המאושרת האחרונה. גם אחרי אישור, זהות המאשר במערכת הנוכחית אינה מאומתת קריפטוגרפית, ולכן אין לחשוף את הממשק החוצה או להתייחס לזה כאל מערכת הרשאות Production.

תדריך המשימה מציג קודם את ה"למה", לאחר מכן עקרונות, החלטות, שאלות פתוחות ותצפיות קוד, עם מקורות ותנאי תחולה. מקורות מצוטטים כ**נתונים**, לא כהוראות לשינוי התנהגות העוזר. זו הגנה חלקית בלבד בפני הזרקת הוראות.
