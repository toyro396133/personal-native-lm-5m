# COMPASS V11.1 — לימוד עצמאי ממשוב חופשי (ללא SELF וללא מודל חיצוני)

**נכון ל־12.10.2026**. זהו ניסוי מחקר נפרד של COMPASS בלבד.

## מה עובד

COMPASS יכול כעת לקלוט אירועי שיחה ישירות מתוך תמלול מקומי, להפריד בין תשובת משתמש להצעה שקדמה לה, לשמור מקור, וללמוד משקלים נפרדים לכל פרויקט. הוא מזהה באופן שמרני רק תיקון שנכתב ממש בצורת `לא X אלא Y`, או `טעות! Y` כשההצעה הקודמת ידועה. **אין כאן מודל שפה או הבנה מלאה של עברית** — זה בסיס ללמידה מקוונת.

תשובות מורכבות אינן נזרקות: הן מופיעות בסקירה המקומית, שבה *המשתמש* יכול לאשר תיקון, להזין את הפירוש שנדחה ואת הפירוש המתוקן, ולצרף נימוק. האישור הזה משמש **דוגמת אימון בלבד**, אינו יוצר החלטת מוצר מאושרת או מחליף עיקרון שמור. זיהוי מקור משיחה מתבסס על תפקידי דוברים ו־IDs שהקובץ המקומי מציג; אין אימות קריפטוגרפי של זהות הדובר.

מנוע הלמידה משתמש במאפייני אותיות ובמשקלים קטנים שנשמרים בקובץ JSON מקומי. הוא מסוגל לדרג שתי חלופות שמוגשות לו מראש, אך **אינו כותב מעצמו החלטות חדשות, מסיק אוטומטית חזון מתוך שיחה או מנהל שיחה חופשית**.

## הפעלה על Windows, ללא API

דרוש Python 3.11 ומעלה וענף המחקר:

```powershell
git fetch origin
git switch experiment/compass-v11-1-freeform-corrections
powershell -ExecutionPolicy Bypass -File .\experiments\compass_v11_1\run_windows.ps1 `
  -MessagesPath "$env:USERPROFILE\Downloads\my-chat-messages.json" `
  -ProjectId "chacham-lev" -OpenReview
```

הקלט הוא **JSON array או JSONL מקומי של הודעות בסדר כרונולוגי**, עם ארבעה שדות לכל הודעה: `session_id`, `id`, `role` (`user` או `assistant`) ו־`text`. זהו פורמט מנורמל לתוכנת המחקר, **לא טענה שהייצוא המקורי של ChatGPT כבר תואם**. להלן נתונים בדויים בלבד:

```json
[
  {"session_id":"session001","id":"message001","role":"user","text":"איך נשמור את עבודת השנה הקודמת?"},
  {"session_id":"session001","id":"message002","role":"assistant","text":"נמחק את הנתונים הישנים"},
  {"session_id":"session001","id":"message003","role":"user","text":"לא למחוק את הנתונים, אלא לשמר אותם ולהוסיף מידע חדש"}
]
```

שלושה שלבים מבוצעים בסקריפט: (1) חילוץ זוגות של הודעות מקוריות לפי הסדר; (2) יצירת קובץ HTML עברי שנפתח בדפדפן ללא חיבור לרשת; (3) אימון ניסיוני על תיקונים מפורשים בלבד. קובצי הנתונים נשארים כברירת מחדל תחת `Documents\CompassPrivate`, **מחוץ ל־GitHub**.

לאחר שמאשרים סקירות בממשק ומשתמשים בכפתור **ייצא קובץ סקירות JSON**, מריצים שוב עם הקובץ שנוצר:

```powershell
powershell -ExecutionPolicy Bypass -File .\experiments\compass_v11_1\run_windows.ps1 `
  -MessagesPath "$env:USERPROFILE\Downloads\my-chat-messages.json" `
  -ProjectId "chacham-lev" `
  -ReviewsPath "$env:USERPROFILE\Downloads\compass-v11-1-private-human-reviews.json"
```

האימון נעשה **לאחר** שנרשם הניסיון של הלומד על ההחלטה הנוכחית. המבחן שקיים כאן בונה את שתי חלופות התיקון מתוך תשובת המשתמש בדיעבד, ולכן הוא **דירוג רטרוספקטיבי בלבד** ולא הוכחת יכולת לחזות החלטה עתידית. כדי לבדוק תחזית אמיתית יש להעביר חלופות לפני קבלת תגובת המשתמש, להריץ `CorrectionCompass.rank`, ורק לאחר מכן לקלוט את המשוב.

## מה נמצא במידע האמיתי עד עכשיו?

ביומן התכנון הפרטי של חכם לב נמצאו 52 תחנות T00–T51, אך רק תגובת משתמש אחת זוהתה אוטומטית עם הניסוח המחמיר של `טעות!`/ניגוד מפורש (T37). **זו מועמדת לבדיקה בלבד; לא נקבעה ממנה זוגיות מאומתת או תוצאת אימון אמיתית.** תשובות אחרות עשירות במשמעות אך דורשות בירור כדי להפוך למשוב נכון.

לכן הפסק המדעי נשאר: **`FREEFORM_FEEDBACK_ENGINEERING_VALIDATED`**, אבל **`COMPASS_PROJECT_INTENT_UNDERSTANDING_NOT_PROVEN`**.

## קוד

- `freeform_feedback.py` — למידת משקלים ותיעוד משוב, ללא מודל חיצוני.
- `chat_ingest.py` — חילוץ רצפי שיחה מקובץ מקומי עם מקור.
- `offline_review.py` — יצירת ממשק HTML מקומי לאישור פירוש התיקון בידי המשתמש.
- `run_windows.ps1` — הרצה מלאה ב־Windows.
- `test_freeform_feedback.py`, `test_chat_ingest.py` — 47 בדיקות הנדסיות מבוססות נתונים בדויים, כולן עברו על שלוש גרסאות Python ב־[GitHub Actions](https://github.com/toyro396133/personal-native-lm-5m/actions/runs/38186804378) (**141 הרצות בדיקה**).

המשך המחקר העיקרי: להבין וללמוד גם תיקון שאינו מכיל ביטוי מילולי קבוע, ולא רק להרחיב עוד ועוד את רשימת התבניות. לשם כך נדרש משוב ישיר ואמין ומדידה עתידית שבה עדיין לא נחשפה התשובה למודל.
