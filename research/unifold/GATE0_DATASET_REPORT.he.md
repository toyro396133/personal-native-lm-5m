# UNIFOLD — Gate 0: מחולל המשימות הראשון

**סטטוס:** קוד מחולל ובדיקות אימות קיימים; אין מודל מאומן, ואין תוצאות למידה.  
**תאריך:** 2026-10-12.

## מה נבנה
- מחולל Python עצמאי ללא ספריות ML או גישה לאינטרנט (taskgen.py).
- שפה סמלית עם **14 פעולות בסיס**, הפועלות על ארבעה ערכים מתוך האלפבית 0–3.
- **L1:** חוק חדש המורכב משתי פעולות. ההפרדה בין אימון, אימות ומבחן היא לפי **התנהגות החוק על כל 256 הקלטים האפשריים**, לא רק לפי כתיבת הפעולות.
- **L2:** חוק המורכב משלוש פעולות, ונבדק שהוא **אינו שקול התנהגותית לשום חוק בן פעולה אחת או שתיים** בשפת המחולל. אין דוגמאות L2 באימון.
- לכל אפיזודה **12 דוגמאות למידה** ו-**16 שאילתות בלי תשובה בקובץ הציבורי**. הפתרונות והתוכניות מוחזקים בקובץ תשובות נפרד answers.PRIVATE.jsonl, שאסור להעביר למודל בזמן מבחן.
- נתוני הבדיקה אינם חולקים חוק זהה מבחינה התנהגותית עם האימון.

## תוצאות Gate 0 המקומיות
הורצו בפועל בתאריך 2026-10-12:

~~~bash
python -m unittest discover -s research/unifold/tests -v
python research/unifold/taskgen.py generate --output /tmp/unifold-10k --count 10000 --seed 42
python research/unifold/taskgen.py validate --output /tmp/unifold-10k
~~~

- **5/5 בדיקות תוכנה עברו.**
- **10,000/10,000 אפיזודות עברו אימות של האורקל, חלוקה, מבנה וגם זיהוי חד־משמעי מתוך דוגמאות התמיכה בתחום המועמדים המוגדר.**
- חלוקה: train_l1=6000, val_l1=1000, test_l1=1000, val_l2=1000, test_l2=1000.
- מלאי חוקים ייחודיים (לא מספר אפיזודות): train_l1=82, val_l1=31, test_l1=23, val_l2=552, test_l2=573.
- חוקים שנדגמו ב-10,000 האפיזודות: train_l1=82, val_l1=31, test_l1=23, val_l2=445, test_l2=457.
- SHA256 משימות ציבוריות: e899ce93375dda439745c82b0b8355450beb7ffb579c6619503a50d7bbc78a5a.
- SHA256 תשובות פרטיות: 917f5db0a1b287786df7a6ac52c3a9bcb0c4a68f5e7e7efe38d4b27ab9b05eba.

**מגבלה מהותית:** יש יותר אפיזודות מחוקים שונים. 10,000 אפיזודות אינן 10,000 חוקים. המחולל בודק **100% זיהוי חד-משמעי מתוך 12 דוגמאות ביחס לכל פונקציות המועמד ברמת L1 או L2**; זה אינו מוכיח זיהוי כשמרחיבים את שפת החוקים מעבר למחולל, אינו מוכיח שמודל מסוגל ללמוד L1/L2, ואינו מוכיח ש-Q משפר את הלמידה. L2 כאן מייצג **הרכבת פעולות ארוכה יותר ומובחנת התנהגותית**, ולא עדיין הוכחה להיררכיית מושגים כללית.

## מה עדיין צריך לפני אימון
1. לבצע מדידות עמימות גם מול שפות חוקים חדשות ומול חוקי L1/L2 משולבים, מחוץ למאגר המועמדים הסגור.
2. להגדיר **רצפי A→B→C** למדידת השפעת ניסיון קודם על רכישת חוק חדש.
3. להוסיף בעתיד מבנים בעלי קינון אמיתי לצד הרכבה רציפה.
4. לסגור תקציבי אימון, בקרות M/Q וספי הצלחה לפני ריצת מודל.
